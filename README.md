# 防犯ラボ

住宅防犯・セキュリティ領域の専門メディア。

## 目的

- Google検索から継続的に集客する
- Google AdSenseとアフィリエイトを両立する
- 賃貸・戸建て・一人暮らしなど住居条件別に最適な防犯対策を案内する
- 一次情報と独自比較を重視する

## 基本方針

- 防犯カメラ比較だけに依存しない
- 防犯診断・比較データ・高品質記事を組み合わせる
- 未確認情報は断定しない
- 実体験のないレビューは公開しない
- モバイルファースト・SEO・速度・アクセシビリティを重視する

## 想定収益

- Google AdSense
- 防犯カメラ・スマートロック等の物販アフィリエイト
- ホームセキュリティ資料請求・見積もり案件

## Status

Repository initialized for site development.

## 現在の実装
- TOP + 4問30秒防犯診断
- 住まい別・防犯機器・ホームセキュリティ・基礎知識の主要記事
- 運営者情報・編集方針・広告表記・プライバシー・お問い合わせ
- robots.txt / sitemap.xml / 404 / canonical / OGP / Article JSON-LD
- 情報記事のみAdSenseプレースホルダ、比較記事はアフィリエイト導線優先

## 公開前チェック
- AdSense審査後に実広告コードを設定
- ASP提携後にdata-affiliate-placeholderを公式リンクへ置換
- お問い合わせ送信先を設定
- 独自ドメイン採用時はcanonical / sitemap / robotsのBASEを一括変更
- 実機レビューは実測データ取得後のみ公開
